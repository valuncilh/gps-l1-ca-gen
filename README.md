# gps-l1-ca-gen

Генератор псевдослучайного C/A кода для сигнала L1 системы GPS.
Ядро — на C, GUI — на Rust (egui/eframe).

Вариант: спутник **SV ID 2** (номер по списку группы).

---

## Принцип работы

Используется стандартная схема GPS L1: два 10-разрядных регистра сдвига (LFSR), G1 и G2.

- **G1** — полином `1 + x³ + x¹⁰` (отводы 3 и 10).
- **G2** — полином `1 + x² + x³ + x⁶ + x⁸ + x⁹ + x¹⁰` (отводы 2, 3, 6, 8, 9, 10).
- **Селектор фазы для SV2** — отводы G2 3 и 7 → `G2i = XOR(3, 7)`.
- **Итоговый код** — `C/A = XOR(выход G1, G2i)`.

Начальное состояние обоих регистров — все единицы (`1111111111`).

---

## Проверка корректности

- Первые 10 бит: `1110010000` (совпадают с эталоном `1620₈` из таблицы IS-GPS-200).
- Период: **1023** такта — после 1023 сдвигов состояние регистров возвращается к начальному.
- Проверено побитовое совпадение C- и Rust-реализаций.

## Функциональность

- [x] Генерация одного периода (1023 бит) — C и Rust
- [x] Динамические отводы селектора фазы (через GUI)
- [x] Проверка периодичности (генерация 1023 + 20 бит, копирование в буфер)
- [x] Автокорреляционная функция (АКФ) на трёх периодах
- [x] Взаимная корреляция (КФ) с двумя дополнительными спутниками
- [x] GUI: тёмная/светлая тема, настройка цвета и толщины линий, отдельное окно графика

## Сборка и запуск

### Требования

- Rust (edition 2021+), `cargo`
- C-компилятор (`gcc` или `clang`)
- На Linux: `libxkbcommon`, `libwayland`/`libX11` (для egui)

### Запуск GUI

```bash
cd gen_app
cargo run --release
