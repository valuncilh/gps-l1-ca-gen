# gps-l1-ca-gen

## Генератор C/A кода для GPS L1 (спутник SV ID 2).  
## Реализован на C, Rust — в разработке (GUI).

### Принцип работы

- **G1**: LFSR, полином `1 + x³ + x⁷` (отводы 3, 7)  
- **G2**: LFSR, полином `1 + x² + x³ + x⁶ + x⁸ + x⁹ + x¹⁰` (отводы 2,3,6,8,9,10)  
- **Селектор фазы для SV2**: отводы G1 3 и 7 → `G2i = XOR(3,7)`  
- **Выход**: `C/A = XOR(выход G1, G2i)`

### Проверка

- Первые 10 бит: `1110010000` (эталон `1620₈`)  
- Период: **1023** такта (состояние регистров возвращается к начальному)
