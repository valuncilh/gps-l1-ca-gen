# Генератор псевдослучайного C/A кода для сигнала L1 системы GPS.
## Реализован на C (ядро LFSR) с возможностью интеграции с Rust (GUI).
## Вариант: спутник SV ID 2 (номер по списку группы).

### Принцип работы:
bash ` - Два 10-разрядных регистра сдвига (G1 и G2) с линейной обратной связью.
- G1: полином 1 + x³ + x¹⁰ (отводы 3, 10).
- G2: полином 1 + x² + x³ + x⁶ + x⁸ + x⁹ + x¹⁰ (отводы 2,3,6,8,9,10).
- Селектор фазы для SV2: отводы G2 3 и 7 → G2i = XOR(3,7).
- Итоговый бит = XOR(выход G1, G2i).
`

### Результат проверки:
- Первые 10 бит кода: 1110010000 (совпадает с эталоном 1620₈).
- Период подтверждён: 1023 такта, состояние регистров возвращается к начальному.

### Функциональность:
- Генерация одного периода (1023 бит).
- Вычисление автокорреляционной функции (АКФ) – для оценки "хорошо".
- Вычисление взаимной корреляционной функции (КФ) с сигналом другого спутника (SV65 или Beidou 32) – для оценки "отлично".

Языки: C (ядро), Rust (GUI в разработке).
Сборка: gcc / cargo.
